আপনার তথ্য কীভাবে সংগ্রহ ও সুরক্ষিত হয়

১. আমরা যা সংগ্রহ করি

  • অ্যাকাউন্ট: নাম, ইমেইল, প্রোফাইল ছবি (ঐচ্ছিক), ভূমিকা (Buyer/Worker)
  • WhatsApp নম্বর: শুধুমাত্র আপনার স্পষ্ট সম্মতিতে, বৈধ প্রচারমূলক টাস্কের জন্য
  • লেনদেন তথ্য: ডিপোজিট/উত্তোলনের নম্বর, TrxID, পরিমাণ
  • টাস্ক তথ্য: আপনার তৈরি/জমা দেওয়া টাস্ক ও প্রমাণ
  • টেকনিক্যাল: টাইমস্ট্যাম্প ও নিরাপত্তা-লগ

২. আমরা যা কখনো সংগ্রহ করি না

❌ WhatsApp OTP / ভেরিফিকেশন কোড
❌ WhatsApp বা অন্য কোনো সেবার পাসওয়ার্ড
❌ অন্য কারও অ্যাকাউন্টে প্রবেশের তথ্য
❌ জাতীয় পরিচয়পত্র / ব্যাংক কার্ডের সংবেদনশীল তথ্য

৩. তথ্যের ব্যবহার

টাস্ক পরিচালনা, পুরস্কার প্রদান, প্রতারণা প্রতিরোধ ও সাপোর্টের জন্য। আপনার তথ্য কোনো তৃতীয় পক্ষকে বিক্রি করা হয় না।

৪. নিরাপত্তা ব্যবস্থা

  • Firebase Authentication — পাসওয়ার্ড হ্যাশ আকারে সংরক্ষিত (আমরা দেখতেও পারি না)
  • Realtime Database Security Rules — প্রত্যেকে শুধু নিজের তথ্য পড়তে/লিখতে পারে
  • Server-side API — ব্যালেন্স ও লেনদেন শুধু ভেরিফাইড সার্ভার অপারেশনে পরিবর্তন হয়
  • ImgBB API key শুধু সার্ভারে — ব্রাউজার কোডে কোনো secret নেই

৫. আপনার অধিকার

প্রোফাইল আপডেট/সংশোধন করতে পারবেন; অ্যাকাউন্ট মুছতে সাপোর্টে যোগাযোগ করুন (আনুমানিক ৭ কর্মদিবস)।

৬. কুকি/লোকাল স্টোরেজ

লগইন সেশন, ভাষা পছন্দ ও UI অবস্থা মনে রাখতে ব্রাউজার স্টোরেজ ব্যবহৃত হয় — ব্যক্তিগত সংবেদনশীল তথ্য সেখানে রাখা হয় না।
